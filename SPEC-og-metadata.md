# SPEC — OpenGraph & Metadata Overhaul

**Status:** Approved, ready to implement (spec'd 2026-07-22).
**Scope owner:** heatpunks.org site.

## 1. Goal & motivation

The current social-share (OpenGraph) images are generated by `/api/og` using a generic template — a plain black background with a radial glow, a system default font, the HRHP logo, and title/subtitle text. When shared on X, Telegram, Nostr, etc. they read as **AI-generated and unintentional**, and they do **not** match the site's cypherpunk/terminal design language.

Alongside the images, the text metadata (tab titles, meta descriptions, OG/Twitter descriptions) is inconsistent and partially stale (e.g. summit dates hardcoded to 2026, a schedule OG still labelled "SUMMIT 2026", the home page has no custom metadata at all).

This overhaul:

1. Replaces the OG image template with a **terminal-window** design that faithfully matches the site (JetBrains Mono, flame gradient, real chrome).
2. Rewrites every page's **tab title** and **meta/OG/Twitter descriptions** with clean, SEO-conventional copy.
3. Ensures **every page** ships a matching OG *and* Twitter card with alt text (today only the root layout defines a Twitter card, so subpages can unfurl on X with the wrong image).
4. Adds **canonical URLs**, reconciles social handles, and reviews **JSON-LD**.
5. Makes the site **agent-ready (AEO)** via a generated **`llms.txt`** and a **sitemap fix**.

Non-goals / out of scope:
- Hand-designed static image files (we keep programmatic generation).
- Per-page markdown endpoints (`/mission.md`) — deferred; `llms.txt` is sufficient at this site's size.
- FAQ / Q&A schema — no Q&A content to back it.
- Explicit AI-crawler rules in `robots.ts` — the existing `userAgent: '*', allow: '/'` already permits all crawlers; leave `robots.ts` unchanged.
- Favicon / app icons (`app/icon.png`, `app/apple-icon.png`) — unchanged.
- Changing the site's own font-loading strategy (globals.css keeps its Google Fonts `@import`).

## 2. Design of the OG image (terminal window)

### 2.1 Canvas
- **Dimensions:** 1200 × 630 (unchanged).
- **Format:** PNG via `next/og` `ImageResponse` (unchanged).
- **Runtime:** `nodejs` (default) — **not** `edge`. **Correction (post-deploy, 2026-07-22):** the initial implementation used `runtime = 'edge'`, which built and worked in local dev, but failed on Vercel: the bundled fonts push the function past Vercel's 1 MB **Edge** Function size limit (`@vercel/og`'s own Satori/Resvg WASM core is already ~2 MB before any custom fonts are added, so Edge was never really viable once custom fonts were involved). Fixed by removing the `runtime = 'edge'` export (Node.js Serverless Functions have a far larger size ceiling) and switching asset loading from `fetch(new URL(..., import.meta.url))` (an Edge-only pattern) to `fs.readFileSync(join(process.cwd(), ...))`, read once at module scope. See `app/api/og/route.tsx`.

### 2.2 Visual anatomy (top → bottom)
1. **Background:** near-black (`#0a0a0a` → `#141414` vertical linear-gradient) with a single flame **radial-gradient** glow in the upper-right (approx `radial-gradient(ellipse at 78% 8%, rgba(255,107,0,0.14) 0%, transparent 46%)`). Radial/linear gradients are Satori-supported.
2. **Noise + scanline texture (optional, graceful):** the site's `feTurbulence` SVG noise and `repeating-linear-gradient` scanlines **do not render in Satori**. Implement texture as a small **base64-encoded PNG tile** applied via `backgroundImage` with `backgroundRepeat`. If the tile causes rendering issues, **omit** — the glow alone is acceptable. Texture is a "nice to have," not a blocker.
3. **Terminal window** — a rounded panel inset from the canvas edges (~6% inset), `border: 2px solid #333`, `borderRadius: ~18px`, semi-transparent dark fill (`rgba(10,10,10,0.72)`), subtle drop shadow:
   - **Title bar:** height ~10% of window. Left: the **HRHP logo mark** (favicon-sized, ~28×28) + three traffic-light dots using brand colors — red `#ff3d00`, yellow `#f9ed32`, green `#00ff41`. Then the window title string: `heatpunks.org — {path}` in muted grey (`#888888`), where `{path}` is the page's title-bar path (see §3). Bottom border `1px solid #2a2a2a`.
   - **Body:** padding ~3%. Monospace content:
     - **Prompt + command line:** the prompt `~/heatpunks $ ` rendered with `~/heatpunks $` — the `$` (and prompt) tinted terminal-green `#00ff41`, the **command** in white `#f5f5f5`.
     - **Wordmark:** large (≈64px), weight 800, **flame-gradient** text (see §2.3), tight letter-spacing.
     - **Meta line (optional per page):** medium (≈28px) white/near-white, e.g. `FEB 26–27, 2027 · DENVER, CO`.
     - **Comment line:** the `//` comment in terminal-green `#00ff41` (≈24–28px).
     - **Cursor:** a **static** solid flame-colored block (`#ff6b00`, ~14×26px) at the end of the last line. (OG images are static — no blink animation.)

### 2.3 Flame-gradient text
Replicate `.text-flame-gradient` from `globals.css`:
```
background-image: linear-gradient(135deg, #ff6b00 0%, #ff3d00 50%, #ff8c33 100%);
background-clip: text;
-webkit-background-clip: text;
color: transparent;
```
`@vercel/og` / Satori supports `background-clip: text`. **Fallback:** if it fails to render in the deployed runtime, fall back to a solid flame fill `#ff6b00` for the wordmark. Verify during implementation (§8).

### 2.4 Fonts (bundled)
- Bundle **JetBrains Mono** `Regular (400)` and `Bold (700)` TTFs in the repo, co-located with the route (e.g. `app/api/og/fonts/JetBrainsMono-Regular.ttf`, `.../JetBrainsMono-Bold.ttf`). JetBrains Mono is OFL-licensed — redistribution in-repo is permitted; include the license note.
- Load them in the edge route via `fetch(new URL('./fonts/JetBrainsMono-Regular.ttf', import.meta.url)).then(r => r.arrayBuffer())` and pass to `ImageResponse({ fonts: [...] })` with correct `name`/`weight`/`style`.
- Body/prompt/comment use weight 400; the wordmark uses weight 700 (rendered heavier via the bold face). Do **not** rely on synthetic bolding.

### 2.5 Logo mark
- Add a **small** optimized logo asset for the title bar (~64×64 PNG) co-located with the route (e.g. `app/api/og/hrhp-mark.png`), read via `fetch(new URL(...))`, or inline as a compact base64 constant. **Remove** the large 180×180 base64 blob currently embedded in `route.tsx` (it inflates the file to ~53k tokens).

## 5. Architecture & files

### 5.1 New: `data/pages.ts` — page inventory (content as data)
Single source of truth per page, consumed by metadata, the OG route, the sitemap, and `llms.txt`.

```ts
export interface PageOg {
  path: string;        // title-bar path, e.g. '~/summit'
  command: string;     // e.g. './register --summit 2027'
  wordmark: string;    // flame-gradient text, e.g. 'HEATPUNK SUMMIT'
  meta?: string;       // optional white sub-line
  comment: string;     // '//' green line
  alt: string;         // OG image alt text
}

export interface PageEntry {
  key: string;                 // og card key + inventory key, e.g. 'summit'
  route: string;               // '/summit'
  title: string;               // <title> segment (home = full descriptive default)
  isHome?: boolean;            // home uses title as absolute default, no template
  description: string;         // meta + OG description
  priority: number;            // sitemap priority
  changeFrequency: 'weekly' | 'monthly' | 'yearly';
  llmsSummary: string;         // one-liner for llms.txt (may equal description)
  og: PageOg;
}

export const pages: Record<string, PageEntry> = { /* home, mission, education, summit, schedule, summit-2025, summit-2026 */ };
```
Card keys: `home`, `mission`, `education`, `summit`, `schedule`, `summit-2025`, `summit-2026`. (`archive` is synthesized in the route for the `[year]` fallback.)

### 5.2 New: `lib/metadata.ts` — `pageMetadata(key)`
Returns a Next `Metadata` object from a `PageEntry`:
- `title`: `entry.title` (Next applies the template for non-home; home is set in the root layout).
- `description`: `entry.description`.
- `alternates.canonical`: `entry.route` (resolved against `metadataBase`).
- `openGraph`: `{ title: ogTitle, description, url: route, siteName, locale: 'en_US', type: 'website', images: [{ url: '/api/og?card=' + key, width: 1200, height: 630, alt: entry.og.alt }] }` where `ogTitle` = `entry.isHome ? entry.title : entry.title + ' | Hashrate Heatpunks'`.
- `twitter`: `{ card: 'summary_large_image', site: '@HashHeatpunks', creator: '@HashHeatpunks', title: ogTitle, description, images: ['/api/og?card=' + key] }`.

This guarantees OG + Twitter + canonical always agree. Reused by every page.

### 5.3 Modify: `app/api/og/route.tsx` (full rewrite)
- Remove the large embedded logo base64 and the stale `getSummitStatus()` date logic.
- Read `card` query param; look up `pages[card]?.og`. Default to `pages.home.og` if missing/unknown.
- Special-case `card=archive`: read `year` param and synthesize `{ path: '~/summit/'+year, command: 'cat archive/'+year+'.txt', wordmark: 'SUMMIT '+year, comment: '// archived event', alt: ... }`.
- Load bundled fonts + logo mark (§2.4/§2.5).
- Render the terminal window per §2.
- Set response cache headers: `Cache-Control: public, max-age=3600, s-maxage=604800, stale-while-revalidate=86400` (cards are static per key; long CDN cache, allow refresh after edits/deploys).

### 5.4 Modify: page metadata
- `app/layout.tsx`: root `metadata` becomes the home/default:
  - `title: { default: pages.home.title, template: '%s | Hashrate Heatpunks' }`
  - `description: pages.home.description`
  - `openGraph`/`twitter` → home card (`/api/og?card=home`) with home alt.
  - keep `metadataBase`, `robots`, `icons`.
  - **JSON-LD (Organization):** review — change `sameAs` `https://twitter.com/HashHeatpunks` → `https://x.com/HashHeatpunks`; verify `logo` (`/images/logo.png` exists), `foundingDate`, `address`. Keep otherwise.

### 5.5 Modify: `app/sitemap.ts`
- Iterate the `pages` inventory to emit entries (`route`, `priority`, `changeFrequency`), so it can't drift from the inventory.
- **Adds the currently-missing `/summit/2026`.** Result includes: `/`, `/mission`, `/education`, `/summit`, `/summit/schedule`, `/summit/2025`, `/summit/2026`.

## 7. Data-model / consistency rules
- OG image URLs are always `/api/og?card=<key>` (or `?card=archive&year=<year>`).
- The route must **never 500** on an unknown/missing `card` — default to the home card.
- Descriptions ≤ ~160 chars where practical (they're within range as written).
- Wordmark text must fit on one line at ≈64px within the window (longest: `HEATPUNK SUMMIT 2026`); verify no clipping (§8) and reduce font size for that card if needed.

## 9. Risks & mitigations
- **Satori feature gaps:** `background-clip: text` and gradients — verify early; solid-flame fallback documented. `feTurbulence` noise / `repeating-linear-gradient` scanlines are **not** supported → use base64 PNG tiles or omit texture.
- **Edge font/asset loading:** must use `fetch(new URL(..., import.meta.url))` (edge has no `fs`). Verify assets are bundled into the edge function at build.
- **Wordmark overflow** for the longest card → per-card font-size guard.
- **Font file size:** two TTFs add ~150–300 KB to the repo (accepted; matches "minimal external deps" over CDN fetch).
